Comparing two permit exports helps separate changes worth inspecting from records you already reviewed. This free tool matches San Francisco DataSF CSV rows by permit number and keeps the earlier and later source values together. A changed permit is not a confirmed equipment purchase.

What each result means

  • Only in later export: the permit ID is absent from your earlier input. It may be an older filing newly included by a changed filter, backfill or export limit. This is not proof of a new project.
  • Only in earlier export: the permit is absent from your later input. It is not established as cancelled, closed or removed from the official dataset.
  • Compared fields changed: a shared status, status date, filed date, description or address differs. Dates are compared at calendar-day precision. Inspect the supplied text and current official record.
  • Ambiguous duplicates: one input contains conflicting versions of a permit ID. The tool does not pick a reliable current version or count it as a confirmed change.
  • Unchanged in compared fields: no difference was found in the fields present in both inputs. A newer Data As Of value alone is excluded from change detection. Other columns and changes between snapshots are outside this comparison.

Use matching exports and retain the dates

Start with the official DataSF Building Permits table. Apply the same filters before exporting each time. Prefer the full filtered export over a truncated screen sample. This tool does not prove that either export is complete.

Primary Address Flag values of N, No, False or 0 are excluded. Missing or unknown primary flags are reported. Repeated permit IDs are grouped; conflicting compared values or source dates produce an ambiguous result. Rows without permit IDs cannot be matched and are reported as excluded.

Each input is limited to 10,000 rows and roughly two million characters. The table shows at most 200 selected records; the comparison CSV includes every selected result. Source dates and supplied descriptions remain in the download. CSV cells that could be interpreted as spreadsheet formulas are prefixed with an apostrophe.

For the dated example, check 1850 Polk St / permit 202608196841. The saved October 20 row records issuance on October 19; it does not prove a coffee-equipment order is still open.
